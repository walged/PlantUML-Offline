# 🌿 PlantUML Offline

Мощный оффлайн-редактор UML-диаграмм с живым предпросмотром, редактором Monaco
и встроенным сервером PlantUML.

> Русская версия README. English version: [README.md](README.md)

---

### ✨ PlantUML Offline — создавайте UML-диаграммы быстро, оффлайн и с мощным движком предпросмотра.

## Возможности

- **Monaco Editor** — профессиональный редактор кода с подсветкой синтаксиса PlantUML
- **Живой предпросмотр** — диаграммы обновляются в реальном времени по мере ввода
- **8 встроенных шаблонов** — классы, последовательность, варианты использования,
  активность, состояния, компоненты, ER и интеллект-карты
- **Экспорт** — в форматы SVG и PNG
- **Масштаб и панорама** — навигация по большим диаграммам колесом мыши и перетаскиванием
- **Встроенный сервер PlantUML** — работает оффлайн благодаря встроенной Java и серверу PlantUML
- **🤖 ИИ-ассистент** — генерация диаграмм по описанию, исправление ошибок, чат и рефакторинг
  (см. ниже)
- **Многоязычный интерфейс** — английский и русский
- **Тёмная/светлая темы**
- **Автосохранение** — ваша работа не потеряется

## 🤖 ИИ-ассистент

В настройках можно добавить API-ключ и подключить LLM-провайдера. Все вызовы
выполняются из бэкенда на Rust (нет проблем с CORS, ключ не попадает в веб-слой).

**Провайдеры:**

- **OpenRouter** (по умолчанию) — один ключ даёт доступ ко множеству моделей
  (OpenAI, Anthropic, DeepSeek, Qwen, Google), OpenAI-совместим, доступен из СНГ.
- **DeepSeek**, **OpenAI**, **Anthropic (Claude)** — прямые провайдеры.
- **Custom (OpenAI-совместимый)** — любой эндпоинт по своему base URL: Qwen/DashScope,
  Kie.AI, локальный Ollama/LM Studio и т.д.

> Примечание: OpenAI и Anthropic напрямую заблокированы для РФ по IP — для СНГ
> используйте OpenRouter или Kie.AI (через «Custom»).

**Функции:**

1. **Текст → диаграмма** — опишите диаграмму на естественном языке, получите код PlantUML.
2. **Исправить с ИИ** — при ошибке рендера кнопка отправляет код и ошибку в LLM и
   предлагает исправление.
3. **Чат-ассистент** — боковая панель с контекстом текущей диаграммы.
4. **Улучшить / отрефакторить** — улучшение стиля и структуры текущей диаграммы.

Ключ хранится локально на вашем устройстве.

## Системные требования

- Windows 10/11 (x64)
- Дополнительное ПО не требуется (Java входит в комплект)
- Для ИИ-функций — интернет и API-ключ выбранного провайдера

## Установка

### Из установщика

1. Скачайте последний установщик `.exe` из раздела Releases
2. Запустите установщик
3. Запустите PlantUML Editor из меню «Пуск»

### Из исходников

```bash
git clone https://github.com/walged/PlantUML-Offline.git
cd PlantUML-Offline
npm install
npm run tauri dev      # режим разработки
npm run tauri build    # сборка релиза
```

## Горячие клавиши

- `Ctrl+S` — сохранить файл
- `Ctrl+O` — открыть файл
- `Ctrl+N` — новый файл
- `Ctrl+Z` / `Ctrl+Y` — отменить / повторить
- Колесо мыши над предпросмотром — масштаб
- `Alt`+перетаскивание — панорама

## Технологии

- **Frontend**: React 18, TypeScript, Vite
- **Десктоп**: Tauri 2.0 (Rust)
- **Редактор**: Monaco Editor
- **Состояние**: Zustand
- **Сервер PlantUML**: встроенный режим picoweb (plantuml.jar 1.2026.6)
- **Java**: Eclipse Temurin JRE 21 (встроенная)
